# Emotion to Action Smart Assistant

## Overview
Emotion to Action Smart Assistant is a multimodal Artificial Intelligence framework designed to understand human emotions through facial expressions, voice signals, and text inputs. The system combines deep learning models to analyze emotions and generate suitable responses/actions.

## Features
- Facial Emotion Recognition using CNN and ResNet-50
- Voice Emotion Recognition using BiLSTM with MFCC features
- Text Emotion Classification using BERT
- Multimodal Emotion Fusion using attention-based mechanism
- Emotion-aware action recommendation
- Explainable AI based emotion analysis

## Technologies Used
- Python
- PyTorch
- TensorFlow / Keras
- OpenCV
- Deep Learning
- NLP
- Computer Vision
- Machine Learning

## System Architecture
The framework consists of:
1. Input Processing Module
   - Face image analysis
   - Voice signal processing
   - Text sentiment analysis

2. Emotion Detection Module
   - CNN / ResNet-50
   - BiLSTM
   - BERT Transformer

3. Fusion & Action Generation
   - Attention-based multimodal fusion
   - Emotion-driven action recommendation

## Datasets
- FER2013
- AffectNet
- RAVDESS
- GoEmotions

## Results
The multimodal approach improves emotion recognition accuracy by combining visual, audio, and textual information.
